# Git Lesson

## リモートリポジトリとローカルリポジトリとはそれぞれ何でしょうか？

- **リモートリポジトリ**：ネット上に配置し、複数人で共有するためのリポジトリ。（個人開発用にも使用可）

- **ローカルリポジトリ**：自分のPC上に配置し、開発者一人ひとりが使用するためのリポジトリ。

## プッシュとマージの違いは何でしょうか？

変更内容の反映先が、リモートリポジトリのブランチか、ローカルリポジトリのブランチかの違い。

- **プッシュ**：ローカルリポジトリのブランチの変更内容を、リモートリポジトリのブランチへ反映。

- **マージ**：同じリポジトリ間で、ブランチの変更内容を別ブランチへ反映。

## コミットとプッシュの違い

変更内容のローカルリポジトリへの記録か、その記録のリモートリポジトリへの反映かの違い。

- **コミット**：git addでステージングエリアに追加された変更内容を確定し、ローカルリポジトリに記録。

- **プッシュ**：ローカルリポジトリのブランチに記録された変更内容を、リモートリポジトリのブランチへ反映。

## コミットのメッセージはどのように書いてあげるのが最適でしょうか？

- git commit -m '変更内容' 

- メッセージは、変更内容が一目でわかるように記述。

## ローカルでマージするフローと、プルリクエストでマージするフローの違いは何でしょうか？
バグの反映の防ぎやすさ。

- **ローカルでマージ**：バグがあってもそのまま反映される。

- **プルリクエストでマージ**：マージ前に作業者とは別の人の確認があるため、バグを発見しやすく、バグがあった場合に反映前に変更ができる。

## コンフリクトを起こしてしまった場合、どう対処すべきですか？

以下のいずれかの方法で変更を取り込む。

1. 先にマージされた変更内容を取り込む

2. 後にマージしようとしている変更内容を取り込む

3. どちらの変更内容も取り込む
